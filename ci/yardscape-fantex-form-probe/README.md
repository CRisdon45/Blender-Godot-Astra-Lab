# Fan-Tex Ash macro-form study

This is a presentation-only species-form experiment. It deliberately does **not** import a plant compendium record or alter the authoritative synthetic tree dimensions.

The current tree record is held fixed so the test isolates recognizable macro form. The Fan-Tex profile uses the retained opaque dab language and two-mesh batching architecture, but reorganizes the crown into six stronger upright scaffold families with a broad rounded/umbrella envelope, moderate internal openings, denser outer masses and a supported upper crown.

The morphology choice is grounded in Arizona/Southwest references describing Fan-Tex / Rio Grande ash as a medium-to-large deciduous shade tree with a rounded-to-broad canopy and strong shade crown. Mature-size values from those sources are **not** applied in this fixture; the future compendium remains responsible for authoritative size/growth data.

No literal compound leaflets are modeled. The question is whether species identity can begin at silhouette, scaffold gesture, density and negative space.

The probe compares the retained generic batched tree and Fan-Tex form from front, side, reverse, top, Plan and courtyard views, verifies deterministic geometry and actual-sun relighting, and preserves the two-mesh architecture.
