# Profile-driven brush-card cloud

This isolated challenger keeps the retained `plant-form-profile/1` inputs, the
shared `PlantFormLayout`, the direct Plan projection, real branch geometry, and
the two-mesh Perspective batching boundary. It changes only the Perspective
foliage surface.

## Visible failure and hypothesis

The retained dab tree uses only a small portion of each normalized lobe
envelope. Plan therefore shows a crown mass that Perspective does not fill, and
the tree reads as scattered marks on exposed scaffolds.

The first native pass used roughly three hundred small opaque bowed polygons.
It filled the crown and cut triangle count, but its hard facets read as polygon
leaves and ring-like clumps. That rejected pass remains in branch history.

The second native pass proved the fixed-center alpha-scissor path, but its
simple oval atlas and unconstrained roll still read as literal leaf confetti;
it also overfilled the airy Palo Verde. That evidence also remains in history.

The third pass restored Palo density and quieted the palette, but constrained
roll made the broad marks stack like shingles. The current pass holds density
and budgets fixed while using four genuinely different cluster silhouettes and
moderate roll.

The revised falsifiable hypothesis is that the stronger prior brush-cloud
mechanic—roughly three hundred small alpha-scissored brush clusters with fixed
3D centers, per-card camera facing, and broad emitter-derived normals—will
produce a calmer and fuller crown without a whole-plant billboard, visible
solid core, literal leaf geometry, extra scene-tree draw objects, or a second
layout authority.

## Boundary

- Fan-Tex Ash and Desert Museum Palo Verde use the same generic builder.
- Every brush card has a fixed 3D center and an emitter-derived broad normal.
- Only each small card faces the camera; the plant and lobe envelopes never do.
- A deterministic generated four-tile brush atlas uses alpha scissor, not blend.
- Each tile is a broad multi-lobed brush cluster, with restrained roll.
- Card budget follows normalized lobe volume, so airy profiles stay airy.
- All wood is merged into one mesh; all foliage is merged into one mesh.
- The shared profile and layout files are inputs and are not modified here.
- Direct Plan remains a separate 2D consumer; no 3D readback is introduced.
- The runner produces fixed dab/brush A/B views and reruns the direct Plan proof.

This is a visual architecture probe, not species certification, production
adoption, artistic acceptance, or target-tablet performance evidence.
