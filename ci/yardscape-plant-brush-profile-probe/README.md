# Profile-driven opaque brush cloud

This isolated challenger keeps the retained `plant-form-profile/1` inputs, the
shared `PlantFormLayout`, the direct Plan projection, real branch geometry, and
the two-mesh Perspective batching boundary. It changes only the Perspective
foliage surface.

## Visible failure and hypothesis

The retained dab tree uses only a small portion of each normalized lobe
envelope. Plan therefore shows a crown mass that Perspective does not fill, and
the tree reads as scattered marks on exposed scaffolds.

The falsifiable hypothesis is that roughly three hundred small, opaque,
camera-independent brush polygons distributed through those same lobe
envelopes will produce a calmer and fuller crown without a solid core, alpha
cutouts, literal leaf geometry, extra scene-tree draw objects, or a second
layout authority.

## Boundary

- Fan-Tex Ash and Desert Museum Palo Verde use the same generic builder.
- Every brush patch has a fixed 3D center and an emitter-derived broad normal.
- All wood is merged into one mesh; all foliage is merged into one mesh.
- The shared profile and layout files are inputs and are not modified here.
- Direct Plan remains a separate 2D consumer; no 3D readback is introduced.
- The runner produces fixed dab/brush A/B views and reruns the direct Plan proof.

This is a visual architecture probe, not species certification, production
adoption, artistic acceptance, or target-tablet performance evidence.
