# Retained brush renderer: shrub generality test

The retained `fixed-center-brush-card-cloud/2` pass is the strongest current
Perspective planting candidate. This probe does not alter its renderer, atlas,
shader, card budget rule, shared layout, or the two retained tree profiles. It
asks whether that exact architecture can represent a low, multi-stem shrub
without reading as a miniature tree.

## Falsifiable hypothesis

A validated `plant-form-profile/1` value with low scaffold starts, radial branch
families, a broad-to-low foliage envelope, and a separate shrub-sized instance
record may be enough for the generic shared layout and retained brush renderer
to produce a convincing shrub archetype.

Reject the current schema/recipe combination if the front, side, top, low, or
courtyard captures read as a short tree, a lollipop crown, a visible central
trunk with foliage perched above it, or a generic ball that cannot coexist with
the retained Fan-Tex tree as a distinct planting class.

## Boundary

- The retained v4 brush renderer is imported unchanged and remains the control.
- The new profile is presentation morphology only; it is a generic dense desert
  mound, not a certified species record.
- The shrub has its own immutable instance record for position, height, crown
  radius, base elevation, and seed.
- The generic dab renderer is retained as an A/B surface baseline.
- Perspective consumes shared 3D anchors/scaffolds; Plan is checked through the
  existing direct `Node2D` profile symbol with no 3D mesh readback.
- Direct Plan tree regressions remain unchanged.
- This is schema and visual-architecture evidence, not production integration,
  approved shrub art, horticultural certification, or tablet performance proof.
