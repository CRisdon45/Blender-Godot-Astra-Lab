# Spatial water and paving material-transfer witness

This is a reviewed renderer/test slice on the existing owner-authorized public worker. The application remains in private Yard-Scape. It is not a new application or plant project.

The opt-in subclass, its three shaders and scene are exact candidate sources. The two display adapters expose only the synthetic courtyard values and spatial renderer. The base renderer's mesh construction, material factory, UI construction, lighting, camera projection and pointer-input methods are preserved. File initialization, persistence, model validation, edit commands and model observation are omitted. Public editing buttons are disabled; test-only fixture resize/rebuild is explicitly not the application's edit/undo/save path. No customer designs, reference images, private core modules, history, credentials or private URLs are included.

The shaders transfer the retained 2D paving wash/joint vocabulary onto lit 3D surfaces. Underwater coloring uses the provided water datum and actual submerged geometry. Stationary caustic-like highlights are illustrative, not a fluid or light-transport simulation. A single translucent surface sits above real basin walls, shelf and floor. No screen texture, static scene image, vertex displacement or TIME repainting is used. Proxy tree and other materials remain unchanged.

The probe compares Plan and oblique Perspective, material group ablations, exact camera/light and style returns, mesh/semantic identities, unchanged unrelated materials, night response, 16 sampled orbit poses and fixture rebuild. It does not establish continuous temporal stability, target-tablet performance, horticultural fidelity, private editing/persistence safety or artistic acceptance.

Native execution is restricted to the Linux GitHub worker with the unchanged checksum-pinned Godot version. Local --verify-only checks only source bytes, dependency boundaries and shader domains. Artifacts contain PNGs, report, bounded logs and source/output hashes, not source archives or private information. The existing two renderer tests and their published results remain unchanged.
