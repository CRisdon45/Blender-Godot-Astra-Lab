# Rounded dab component comparison

This is a component-only geometry test on the approved public worker. It inherits the exact retained dab-group v2 cluster recipe: 24 marks, four cluster centers, the same random stream, mark dimensions, twig gestures, opaque material and scene lighting. Only each dab primitive changes from one equatorial ring to two staggered rings.

The original group is 366 indexed triangles. The rounded candidate is intentionally bounded at 654. No whole-tree, tablet-speed or production claim follows from that increase.

Front, reverse, quarter and top views are compared before any whole-tree assembly. If the extra ring does not visibly reduce the pointy/faceted mark read, the candidate should be parked rather than multiplied across sixteen groups.
