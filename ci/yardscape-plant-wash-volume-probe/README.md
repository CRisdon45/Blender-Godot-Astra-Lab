# Profile-driven 3D wash-volume challenger

The retained brush-card pass is the strongest card-based planting result, but
authored masks and broader cards made its card construction more visible rather
than less. This isolated challenger changes only the Perspective foliage
surface while preserving the same `plant-form-profile/1`, `PlantFormLayout`,
branch geometry, direct Plan projection, and two-mesh batching boundary.

## Falsifiable hypothesis

Two overlapping low-resolution closed wash volumes at each shared profile
anchor may read as connected Northstar light/mid/dark foliage masses while
remaining stable during orbit. The volumes use real 3D centers and silhouettes,
stable object-space pigment, broad emitter-derived normals, ordinary opaque
depth, and one merged foliage mesh. There are no alpha cards, billboards,
literal leaves, runtime texture generation, or runtime AI.

Reject the representation if front, side, top, or courtyard captures read as
rocks, plastic balloons, one solid crown blob, or generic geometry that erases
the difference between Fan-Tex Ash and Desert Museum Palo Verde.

## Boundary

- The retained brush-card tree is the A/B control.
- Fan-Tex and Palo use the same generic wash-volume builder.
- Shared normalized anchors, scaffold paths, and Plan lobes are unchanged.
- Each profile group contributes two interpenetrating closed volumes.
- Wood is one merged mesh; foliage is one merged mesh.
- Pigment is object-space and deterministic; camera movement never regenerates
  geometry or reshuffles value regions.
- Direct Plan remains an independent 2D consumer with no 3D readback.
- This is visual architecture evidence, not species certification, artistic
  acceptance, Yard-Scape integration, or tablet performance evidence.
