# Interleaved shoot-tree probe

This bounded continuation assembles sixteen copies of the already tested compact seven-leaf shoot at the existing generic branch-anchor locations. It reuses the prior tapered branch gesture and the same spatial courtyard, water and paving. It is not a species asset or a new plant framework.

The intent is to test representation scale: can many small closed 3D forms merge into an illustrative canopy without becoming broad sheets or literal leaf noise? Each shoot remains opaque and uses final-mesh normals. No alpha foliage, billboard, canopy-wide normal override, wind, runtime AI or density-lighting approximation is introduced in this pass.

The old proxy remains a reversible control. Native evidence is a small-look gate: Plan, normal Perspective, close front/reverse, and a top canopy view plus basic source/geometry/determinism checks. No private model/edit/save code, customer files, supplied references, credentials or history are published. Passing does not establish tablet performance or artistic acceptance.
