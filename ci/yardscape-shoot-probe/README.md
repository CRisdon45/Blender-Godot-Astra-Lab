# Compact 3D foliage shoot probe

This is a bounded renderer experiment on the owner-approved public worker. It tests one generic broadleaf shoot made from a short twig and seven small closed 3D leaf forms. It is not a species asset, a new plant framework, or application authority.

The probe reuses the existing read-only spatial courtyard adapter and retained water/paving materials. The shoot uses final-mesh normals computed from its actual indexed triangles. There is no canopy-wide normal guide, alpha card, billboard, runtime AI, wind, or implicit-density approximation in this first look.

The native comparison captures the group in isolation from top/front/reverse views and at one existing tree anchor in the same courtyard. Source tree placement and dimensions are read from the existing synthetic record. Private model/edit/save/undo code, customer designs, supplied references, credentials, and repository history are not included.

A successful technical probe is not artistic acceptance or tablet-performance evidence. If the small group still reads as a flat plate or a pile of pebbles, it should be changed or parked before assembling a whole canopy.
