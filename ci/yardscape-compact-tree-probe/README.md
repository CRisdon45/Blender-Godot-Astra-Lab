# Compact-group whole-tree first look

This is a deliberately small follow-up to the successful compact-group witness. It assembles sixteen copies of the same generic compact-group grammar at the retained branch anchors in the existing spatial courtyard, using the prior branch gesture and current water/paving. It is a visual hypothesis, not a species model, production tree, performance result or new architecture.

The tree uses final-mesh normals inside each compact group and no whole-crown normal guide. Groups are deterministic but use different derived seeds and yaw. The branch skeleton is reused from the prior generic witness; its old foliage is hidden. No alpha cards, billboards, reference images, TIME noise or runtime AI are introduced.

This first look is intentionally not a broad regression suite. It verifies deterministic assembly and basic source invariants, then captures Plan, courtyard, close front/reverse/quarter/top and a light return, plus the original structural proxy. If the tree reads as a repetitive bouquet or oversized literal leaves, stop here and change the grouping grammar rather than adding effects. If the whole form reads coherently, then run a bounded second pass for silhouette hierarchy, batching/performance hypotheses and richer Plan/Perspective comparison.
