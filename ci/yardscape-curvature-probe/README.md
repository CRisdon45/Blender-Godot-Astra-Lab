# Curvature and limited cutout comparison

Application development remains in private Yard-Scape. This is the existing approved public renderer/test host, not a separate plant app. Only new original renderer/test code and one generated 128x128 coverage mask are introduced. No private core, editing/persistence, reference images, customers, credentials or history are published.

The first look rounded and curved 64 foliage carriers but still read as oversized sheets. It is preserved at commit 0b97a373eb62a1e13504da5f2e60c312543af69d / run 35227703818. The second look adds UVs and an original generic silhouette mask, with color-only pigment and live scene lighting retained. The same 64 carriers, source record, branch geometry, group anchors, palette, light and site stay fixed. The coverage-off comparison isolates the cutout variable. Alpha scissor introduces fragment/coverage cost and is not asserted to be cheaper than opaque foliage.

The original folded default scene is unchanged in selection: a small factory seam returns its original generator. Only the new opt-in scene selects the curved-cutout subtype. The shared 128x128 texture is decoded once from a checksum-tracked embedded PNG; no import pipeline, network, image generation or color/shadow bake runs in the product. Curved carriers have more triangles than the prior folded shape; both remain below the old sphere proxy's count. These are geometry counts, not performance evidence.

Quick mode captures ten paired views and checks exact branch/source/group identity and mask-toggle return. Full mode reuses the 54-check canopy probe with only three scene/class paths changed; baseline mode runs that same probe over the original folded scene with the factory seam. Original assertions and thresholds remain intact. The two white mask views in the reused full probe depict carrier geometry, not alpha-tested foliage coverage, and must not be used to claim cutout-hole statistics. The legacy assertion mentioning no cards checks only the two child mesh nodes, not the material's coverage path.

Both existing read-only spatial adapters remain unchanged. Private editing/undo/save and physical-tablet performance are not tested. Native engines execute only on the public Linux GitHub worker with the original checksum pin. Evidence retains native images, bounded logs, reports and source/output hashes. Original owner code receives no additional blanket license.
