# Volumetric paint-dab foliage group

This starts a new representation hypothesis after two shoot-group looks remained too twig-like. Twenty-four tiny closed 3D marks in four overlapping clusters sit around three simple twig gestures. The marks are intended to behave like volumetric brush dabs: smaller than the prior enlarged-leaf forms, directional but not literal botanical leaves, and much smaller than the rejected cloud lobes.

The candidate uses final-mesh normals, opaque merged geometry and the same restrained pigment shader. No crown guide, alpha cards, billboard, reference image, TIME noise or runtime AI is added. The prior compact group is the visual control. If the dabs read as gems, confetti or pebbles instead of foliage, reject the hypothesis rather than increasing mark density.
