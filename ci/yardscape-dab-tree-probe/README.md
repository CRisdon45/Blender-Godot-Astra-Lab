# Hierarchy-aware volumetric-dab tree

This whole-tree witness changes only the local foliage-group grammar inside the retained compact-tree hierarchy. The same sixteen branch anchors, five primary / ten secondary / one leader roles, scale factors, tilts, source tree record, branch skeleton, water, paving and cameras are preserved. The prior compact-group tree is captured side-by-side.

Each new group uses 24 small solid dabs around three twig gestures. There is no alpha foliage, crown-normal guide, billboard, reference image, TIME noise or runtime AI. The expected geometry count is substantially below the compact tree, but no performance claim is made without device profiling. If the assembled tree reads as confetti or a gem-covered tree, reject it even if its component looked good.

Second-look note: the local dab grammar is now `volumetric-paint-dabs/2`. The same 24 marks and 366 total group triangles are retained, but their footprint and individual mark dimensions were enlarged to match the compact control more fairly. This README-only change deliberately retriggers the unchanged whole-tree probe after that reviewed dependency update; hierarchy, test thresholds and tree assembly code remain unchanged.
