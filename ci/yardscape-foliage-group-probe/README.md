# Compact generic foliage-group witness

This is the next bounded visual experiment from Yard-Scape's research-to-code checkpoint. It does not introduce a species library or replace the current application tree. One deterministic branch-tip group made from eleven small closed interleaved 3D forms is evaluated inside the existing spatial material courtyard.

The candidate uses final-mesh normals only. There is no crown-normal guidance, alpha card, billboard, TIME noise, screen texture, runtime AI, reference image, or baked light direction. The purpose is to judge whether genuinely smaller volumetric forms avoid the sheet/rock failure before assembling a whole tree.

The public worker reuses the same read-only spatial display adapter. Private model/edit/undo/save code, customer designs, supplied reference images, credentials and history remain excluded. A passing probe is a geometry/rendering witness only, not Northstar acceptance or tablet performance evidence. If the compact group still reads as pebbles, plastic leaves, or a regular star from front/reverse/top views, do not assemble it into a full tree.
